================================================================================
                    EMERGENCY STOP LOSS - QUICK START
================================================================================

WHAT IS IT?
  Automatic protection that squares off ALL positions if any position hits 10% loss

WHY USE IT?
  ✅ Protects capital automatically
  ✅ No manual intervention needed
  ✅ Prevents catastrophic losses
  ✅ Professional risk management

HOW IT WORKS?
  1. Bot monitors all open positions continuously
  2. Calculates loss % for each position
  3. If ANY position hits 10% loss → EMERGENCY TRIGGERED
  4. Squares off ALL positions immediately using MARKET orders
  5. Stops placing new orders
  6. Continues monitoring until market close

================================================================================
                    LOSS CALCULATION
================================================================================

BUY POSITION:
  Loss % = ((Entry Price - Current Price) / Entry Price) × 100
  
  Example:
    Entry: 100
    Current: 90
    Loss: ((100 - 90) / 100) × 100 = 10%

SELL POSITION:
  Loss % = ((Current Price - Entry Price) / Entry Price) × 100
  
  Example:
    Entry: 100
    Current: 110
    Loss: ((110 - 100) / 100) × 100 = 10%
