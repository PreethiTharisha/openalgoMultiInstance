================================================================================
                    SMART CONTINUOUS TRADING BOT
================================================================================

WHAT IS IT?
  Intelligent trading bot that:
  ✅ Places orders at calculated prices
  ✅ Waits for order execution
  ✅ Monitors price continuously
  ✅ Only places new orders when needed
  ✅ Avoids spam orders
  ✅ Tracks statistics

================================================================================
                    HOW IT WORKS
================================================================================

STEP 1: Get Current Price
  Current LTP: Rs.980.90

STEP 2: Calculate Order Prices
  BUY Price:  Rs.975.90  (Current - 5)
  SELL Price: Rs.985.90  (Current + 5)

STEP 3: Place Orders
  Place BUY order at Rs.975.90
  Place SELL order at Rs.985.90
  Status: PENDING

STEP 4: Monitor Price (Every 5 seconds)
  Check: Is price still 980.90?
  If price moves 2+ Rs, consider new order

STEP 5: Check Order Status (Every 10 seconds)
  Is BUY order filled? If yes, place new order
  Is SELL order filled? If yes, place new order

STEP 6: Place New Orders (Only when needed)
  If previous order filled → Place new order
  If price moved 2+ Rs → Place new order
  Otherwise → Wait and monitor

REPEAT: Cycle continues...

================================================================================
                    CONFIGURATION
================================================================================

Default Settings:
  STOPLOSS_AMOUNT = 5.0          # 5 rupees loss
  PROFIT_TARGET = 10.0           # 10 rupees profit
  PRICE_OFFSET = 5.0             # Place order 5 Rs away
  PRICE_CHECK_INTERVAL = 5       # Check price every 5 seconds
  ORDER_STATUS_CHECK_INTERVAL = 10  # Check status every 10 seconds
  SIGNIFICANT_PRICE_MOVE = 2.0   # If price moves 2+ Rs, place new order

For Scalping (Fast):
  PRICE_OFFSET = 2.0
  PROFIT_TARGET = 5.0
  STOPLOSS_AMOUNT = 2.0
  PRICE_CHECK_INTERVAL = 2
  SIGNIFICANT_PRICE_MOVE = 1.0

For Swing Trading (Slow):
  PRICE_OFFSET = 10.0
  PROFIT_TARGET = 20.0
  STOPLOSS_AMOUNT = 10.0
  PRICE_CHECK_INTERVAL = 30
  SIGNIFICANT_PRICE_MOVE = 5.0
