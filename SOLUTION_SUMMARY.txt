================================================================================
                        KEY DIFFERENCES
================================================================================

BROKER API KEY vs OPENALGO API KEY:

Broker API Key (wxyz123):
  - Purpose: Authenticate with broker
  - Length: Varies (8-256 characters)
  - Format: Broker-specific
  - Where: Broker's website/app
  - ❌ NOT what you need for OpenAlgo SDK

OpenAlgo API Key (0aac0bae...fae9a165):
  - Purpose: Authenticate with OpenAlgo platform
  - Length: Always 64 characters
  - Format: Hexadecimal (0-9, a-f)
  - Where: OpenAlgo /apikey page
  - ✅ THIS is what you need!

================================================================================
                        BEFORE & AFTER
================================================================================

BEFORE (❌ Wrong):
------------------
BROKER_API_KEY = wxyz123  # Only 8 characters!

client = api(
    api_key='wxyz123',  # ❌ Fails validation
    host='http://127.0.0.1:5000'
)

AFTER (✅ Correct):
-------------------
import os

OPENALGO_API_KEY = os.getenv('OPENALGO_API_KEY')  # 64 characters

if not OPENALGO_API_KEY or len(OPENALGO_API_KEY) != 64:
    print("ERROR: Invalid API key")
    exit(1)

client = api(
    api_key=OPENALGO_API_KEY,  # ✅ Valid 64-char key
    host='http://127.0.0.1:5000'
)
